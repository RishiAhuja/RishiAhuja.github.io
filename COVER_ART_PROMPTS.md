# Researcher Portfolio Cover-Art Prompts

## Shared prompt prefix

Use this prefix before every individual prompt below:

> Create one original, high-resolution 3:4 portrait cover artwork for a research-portfolio card, exported as an opaque PNG at 1200×1600 or the nearest available 3:4 size. This is the inner artwork only: do not add the website’s outer color mat, title, caption, frame, or border. Use contemporary editorial abstraction for an AI and systems researcher—concept-first composition, precise smooth vector geometry or a controlled procedural texture, confident large shapes, a restrained palette, and clean negative space. The image must remain clear when displayed at approximately 220×295 px inside a 4:5 card. Absolutely no pixel-art styling, visible raster squares, retro game graphics, text, letters, numbers, formulas, logos, watermarks, generic stock-icon glyphs, UI screenshots, photorealism, 3D mockups, or drop shadows. Do not reproduce any existing project artwork; create a new visual metaphor with its own composition.

The website should place each generated 3:4 image at 80% size, centered and non-repeating, inside its specified 4:5 outer mat color.
